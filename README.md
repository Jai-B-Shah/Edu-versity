# AI & Machine Learning Internship — Edu-versity

This repository documents an AI/ML internship completed at Edu-versity, where predictive analytics models were developed and evaluated on real-world datasets using core Python data science and deep learning tools. The internship focused on applying machine learning techniques to practical, data-driven problems rather than purely theoretical exercises.

Alongside the internship documentation, this repo also includes two independent practice projects built to apply and demonstrate the same skill set (NumPy, Pandas, Scikit-learn) on classic, well-known datasets.

## Skills & Tools Demonstrated

- Python for data analysis and model development
- NumPy and Pandas for data manipulation and preprocessing
- Scikit-learn for model training and evaluation (classification and regression)
- Keras for building and training deep learning models
- Exploratory data analysis and data visualization (Matplotlib, Seaborn)
- Predictive analytics on real-world datasets
- End-to-end workflow: data preparation, model development, evaluation, and interpretation

## What Was Built

- AI/ML models for predictive analytics applied to real-world datasets, developed as part of the internship curriculum
- A structured project report documenting the internship projects, tools used, working procedure, and key learning outcomes
- **Breast Cancer Diagnosis Classification** (`Projects/breast_cancer_classification/`) — a supervised classification project predicting malignant vs. benign tumors from the Wisconsin Diagnostic Breast Cancer dataset, comparing Logistic Regression and Random Forest models
- **Diabetes Progression Prediction** (`Projects/diabetes_progression_prediction/`) — a supervised regression project predicting diabetes disease progression from baseline patient measurements, comparing Linear Regression, Ridge Regression, and Random Forest models

## Results

- Successfully completed the AI/ML internship, evidenced by an official Letter of Recommendation from Edu-versity's Academic Head, citing strong performance in applying AI concepts, tools, and techniques to real-time problems
- Produced a formal project report summarizing the work undertaken during the internship
- **Breast cancer classification:** Logistic Regression achieved 98.2% test accuracy and 0.995 ROC-AUC; Random Forest achieved 95.6% test accuracy and 0.993 ROC-AUC, on a held-out test set of 114 patients
- **Diabetes progression prediction:** Linear Regression achieved the best test-set fit (R² = 0.453, MAE = 42.8) among the three models compared, with BMI, blood pressure, and serum triglyceride levels among the strongest predictors — consistent with established clinical risk factors
